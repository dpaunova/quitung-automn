# Memory

Raw facts go here as one file per fact. The `/dream` skill consolidates them into `memory/DREAM.md`.

## Format

Each memory file uses YAML frontmatter:

```markdown
---
name: short-slug
description: One-line summary
owner: github-username
type: project | convention | gotcha | person
verified: YYYY-MM-DD
---

The fact itself.
```

## Rules

- One fact per file.
- Never hand-edit `DREAM.md` — it is generated by `/dream`.
- Stale facts get a `stale: YYYY-MM-DD reason` line in frontmatter.
